# Detalle de Girasoles

Un pequeño detalle hecho con HTML, CSS y JavaScript.

La página muestra un ramo de girasoles animado, diseñado principalmente para dispositivos móviles, con un mensaje especial y una ambientación interactiva.

Incluye:

- Animación de entrada del ramo.
- Fondo animado con estrellas.
- Modo día y modo noche.
- Cambio manual de tema.
- Efectos interactivos al tocar la pantalla.
- Diseño responsive para móvil y escritorio.
- Todo el diseño contenido en un único archivo HTML.
